# 《奪唐：朱全忠傳》企劃

唐末回合制 RPG。主角是朱溫：從碭山窮小子、黃巢部將、降唐賜名「全忠」，到挾天子、弒君、受禪稱帝。年代 864～907 年，片尾帶到 912 年朱友珪弒父與五代十國割據。

專案資料夾與 repo 目前還叫 `jiangdong`，改名要另外決定。

## 故事核心

- **一句話**：他的名字叫「全忠」，他一生做的事是奪唐。
- **主線情感**：張惠是朱溫唯一怕的人，也是他的良心。她在世時，朱溫還會收手；她一死（904），弒君、白馬驛接連發生。
- **死對頭**：李克用。上源驛一夜結下四十年的仇，第三章起反覆出現，是全作的宿敵。
- **主角不洗白**：不把朱溫寫成好人，也不寫成只會殺人的怪物。他聰明、有魅力、會用人，也越走越狠。玩家要親手走完這條路。

## 玩法

- **大地圖**：真實經緯度換算的中國地圖，黃河、長江、淮河、汴河、太行、秦嶺都有；一度五格。可以自由走，走路線才遇敵少。城市插旗：紅旗我方、藍旗敵方。
- **城市**：故事城市進城是地圖關卡；其他城市是補給選單（休息、買糧）。
- **城堡關卡**：俯視磚塊迷宮，有城牆、走道、守軍、寶箱、絞盤開門、烽火台存檔點，走到底打主將。
- **戰鬥**：兵力即血量、兵越少打越輕；計略共用「計」；騎剋弓、弓剋步、步剋騎；陣形；地形；勸降；全軍自動。
- **不拖時間**：沒有登入獎勵、儲值、等待。輸了從最後的烽火台繼續，保留經驗與錢。

## 美術方向

FC 紅白機時代的 RPG 感：

- 限定 NES 色盤（`js/palette.js`，python 匯入工具同一份）；16×16 圖塊；黑底白框視窗；游標選單；一個畫面的格子數接近當年機器。
- 直向手機版：上半是遊戲畫面（一個遊戲像素＝兩個 CSS 像素，不糊），下半是對話框、指令或十字鍵＋AB 鍵，提示不會擋到畫面中間。
- 人物頭像、標題圖：GPT 生成，依史實與唐末服飾（幞頭、圓領袍、鐵札甲），稍微美化，再轉成 48×48、NES 色的真像素。李克用留獨眼特徵，鴉軍黑甲。
- 圖塊、戰場小兵、地圖人物：程式畫，保證是真 8-bit 的硬邊與色數。
- 類型與年代感參考當年的 RPG，**但圖塊、地圖、介面、人物、音樂都是原創**，不描、不拷任何既有遊戲的素材，也不放任天堂商標。

## 音樂

WebAudio 模擬 FC 四聲道：兩個方波（12.5／25／50% 佔空比）、三角波低音、雜訊鼓。全部原創，五聲音階。

## 檔案

- `js/palette.js`：NES 色盤
- `js/world.js`：經緯度 → 大地圖
- `js/castles.js`：城堡與村莊的 ASCII 地圖
- `js/story/`：每章一個檔案，寫人物位置與事件
- `js/data.js`：所有數值（改完跑 `node tools/sim.js`）
- `tools/make_jobs3.py`：GPT 工作清單；`tools/import_art.py`：轉真像素
